# 🏚️ SeismoSafe — Earthquake Vulnerable Building Detection & Risk Analysis System for Bangladesh

> A smart, data-driven platform for identifying seismically vulnerable buildings across Bangladesh, empowering residents, owners, and inspectors with actionable risk insights.

---

## 📌 Overview

SeismoSafe is a web-based system designed to detect earthquake-vulnerable buildings and  risk analysis of it using Risk Score across Bangladesh. The platform brings together building owners, residents, and professional inspectors under a unified system — enabling proactive risk management before disasters strike.

---

## 🧩 Core Entities

| Entity | Description |
|---|---|
| **User** | General platform user |
| **Owner** | Individual who registers and manages a building |
| **Inspector** | Certified professional who evaluates buildings |
| **Residence** | Occupant of a registered building |
| **Building** | The physical structure registered in the system |
| **Risk Score** | Computed vulnerability score assigned to a building |
| **Rental_Request** | Who send request for take rent the building rooms |
| **to_let** | where all the to-let are saved with details like rent, no of rooms|
| **payment** | all the request payement details|

## ✨ Features

### 1. 🏗️ Building Mangement System
Owners can input and save detailed building information into the system, creating a unique and traceable record for each property.

### 2. 📋 Complaint Management System
Residents and owners can file complaints about building-related issues. Complaints support photo uploads alongside detailed text descriptions for accurate documentation.

### 3. 🏠 Building Info with Risk Score to check Vulnarability
A dedicated view presenting all relevant information, specifications and vulnerable Risk Score calculation using facility Score,floor_score,material_score,construction_score.

### 4. 🛠️Admin Control Panel
A admin control panel from where a admin can add and drop building , can add a professional inspector to inspect complains, also can assigned inspector to check the complain from its end.

### 5. 🤖Inspector Panel
An inspector Panel from where a inspector can see his complains he is assigned to check and solve them. From his end he can change the status according to his working condition(pending,working,solved). After the visit of the building he can give a details report with discription and photos.

### 6. 🗺️ Profile Management
According to the user every user will get different option from their end to edit like a tenant can update moving_date,owner can update construction

### 7. 👤 To Let Management 
There is a option in owner end to post to let and can see how many request he gets for rent one the other hand tenant can see vacancy and can send request to the owner to give him rent
### 8. Payment Gateway
A online payment gateway to pay advance for take the building room rent
